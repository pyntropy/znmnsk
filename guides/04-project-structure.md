# 04. Структура проекта

Компоненты разбиты по модулям. Расположение определяется областью видимости:

```
src/
├── components/              ← общесистемные компоненты (Button.vue, Input.vue)
├── modules/                 ← модули (фичи)
│   └── <feature>/
│       └── components/      ← компоненты, которые использует только этот модуль
├── assets/
│   └── main.css             ← глобальные стили (Tailwind)
├── App.vue
└── main.js
```

## Правила

- **Общесистемный компонент** — переиспользуется несколькими модулями → `src/components/`.
- **Модульный компонент** — нужен одному модулю → `src/modules/<feature>/components/`.
- Если модульный компонент начал использоваться вторым модулем — поднять его в `src/components/`.
- Имена файлов — PascalCase (`Button.vue`), импорт относительный.
- CSS-утилиты Tailwind — прямо в `<template>`, глобальный `@import "tailwindcss"` — только в `src/assets/main.css`.
